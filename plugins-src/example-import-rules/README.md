# Example: Import Rules (Declarative)

Демонстрирует возможность `mouvi-engine`: **importValidation** через декларативные `importRules` (без runtime-кода).

## Что проверяет
- URI-схема: `mouvi-rules://...`
- Маркер в тексте: `[MouviRulesExample]`

## Как проверить
1. Установите `.mu` в Mouvi (Настройки → Плагины).
2. Импортируйте конфиг/текст: `mouvi-rules://demo` или `[MouviRulesExample]`.

Плагин распознает ввод без выполнения JS-кода.
