# Example: UI Extensions

Демонстрирует возможность `mouvi-engine`: **uiExtensions** (`getUiExtensions`, `onUiAction`).

## Возможности
- Декларативные элементы UI (text, keyValue, divider, button)
- Обработка действий пользователя
- Персистентное состояние в `ownStorage`

## Как проверить
Установите плагин и откройте его расширение в **Настройки → Плагины**.
