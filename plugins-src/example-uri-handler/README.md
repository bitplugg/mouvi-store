# Example: URI Handler

Демонстрирует возможность `mouvi-engine`: **uriHandlers** (`handleUri`).

## Возможности
- Перехватывает/обрабатывает URI вида `mouvi-uri-example://...`
- Возвращает `{ handled: true, ... }` при совпадении
- Сохраняет последний обработанный URI и показывает его в UI

> Примечание: вызов `handleUri` выполняется в сценариях, где приложение передаёт URI активным плагинам.
