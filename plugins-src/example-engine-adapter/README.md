# Example: Engine Adapter

Демонстрирует возможность `mouvi-engine`: **engineProvider** (`prepareEngineConnection`).

## Идея
Плагин-адаптер принимает кастомный/неподдерживаемый формат и преобразует его в конфиг, который может обработать **нативно поддерживаемый движок** Mouvi (`wireguard`, `amneziawg`, `vless`).

## Демо
- Вход: `mouvi-adapter://demo` (или `[MouviAdapterDemo]` в контенте)
- Выход: `handled: true`, `protocol: "wireguard"`, валидный (демонстрационный) WireGuard-конфиг

> Важно: динамическая загрузка произвольных нативных/TUN-движков из `.mu` не поддерживается. Этот пример показывает именно адаптацию к существующему нативному стеку.
